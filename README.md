# proberesume1

Probe tool used to detect when GitHub lifts repository creation throttling.

**Site:** https://theworker02.github.io/proberesume1/

## Install / run

```bash
git clone https://github.com/theworker02/proberesume1.git
cd proberesume1
node src/cli.js
node --test
```
